About

Tools change every year. Frameworks come and go. But probability, optimization, linear algebra, and statistical inference haven't changed in decades — and everything I build starts from that ground.

That's the thread running through my work: using rigorous, mathematical thinking as the foundation, and letting the tools around it evolve.

I care less about whether a model is impressive, and more about whether it holds up — under uncertainty, under real constraints, under conditions the training data never saw.

That's why, given the choice, I reach for methods that reason explicitly about uncertainty rather than ones that just predict a number and hope. It's a slower way to build. It's also a more honest one.

My curiosity moves across domains — but it's really the same set of questions, asked in different rooms.

Lightweight Intent-Aware Network Slicing for 5G

Letting a 5G network understand intent, not just enforce static rules.

Problem5G networks must allocate resources across very different service types (eMBB, URLLC, mIoT) under strict QoS/SLA constraints, and static slicing rules don't adapt to real-time, diverse traffic.

ApproachAn NLP layer parses natural-language service requests into structured intent; a Graph Neural Network (R-GCN/GAT) predicts slice-level KPIs like delay, jitter, and loss; a Reinforcement Learning module (PPO/DQN) handles admission and resource allocation; an explainability layer (SHAP, Captum) keeps decisions interpretable.

OutcomeA lightweight, end-to-end simulated framework for real-time, adaptive slice management — with built-in transparency for why each slicing decision was made.
